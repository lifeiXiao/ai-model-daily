收录规则与更新说明

模型库：每个配置账号采集最新 30 个仓库，首次收录最近 90 天的记录，之后保留一年历史。量化版、预览版等独立仓库可能分别出现，因此仓库数量不等于独立模型数量。本项目不是全网模型全集。

功能：依据 Hugging Face 的任务类型和明确标签整理中文说明，不运行模型、不生成性能排名。公开的模型仓库可能有申请访问或商业限制；请以模型卡中的许可为准。

公告：按标题中的模型相关关键词筛选，保留简短原文节选。日期使用官方公告日期；模型卡的仓库创建日期不代表正式发布日期。

更新：由 GitHub 托管的任务每日采集并发布，定时任务可能延迟。单个来源失败时保留历史记录，并在下方标记；若某一类来源全部失败，则不覆盖上次发布内容。首次导入单独记录，不计为“本日新发现”。

每日归档位于仓库的 daily 目录，运行情况可在 Actions 日志 中查看。
